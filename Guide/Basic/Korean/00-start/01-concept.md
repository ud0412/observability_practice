# 00 설명 — 어디에서 시작하나요?

이 과정의 출발점은 이미 준비된 Kubernetes입니다. Kubernetes를 만드는 방법은 선행 과정에서 배웁니다. 여기서는 그 위에 데이터를 수집하고 저장하고 보는 도구를 올립니다.

필요한 저장소는 두 개입니다. `wsl_kubernetes_practice`는 클러스터와 네트워크를 관리하고, `observability_practice`는 관측 도구와 샘플을 관리합니다. 같은 WSL 사용자로 실행해야 같은 클러스터와 저장 경로를 사용할 수 있습니다.

`kubectl`은 클러스터에 명령을 보내는 도구입니다. **kubeconfig**는 어느 클러스터에 어떻게 접속하는지를 담은 파일입니다. 다음 실습에서는 전용 kubeconfig를 선택하고, 노드 두 개가 Ready인지 확인합니다.

이 교본에는 두 경로가 있습니다. 수동 경로는 각 구성 요소를 직접 적용하며 배우는 방법이고, 자동 경로는 동일한 인프라를 한 번에 준비하는 방법입니다. 두 경로는 같은 설정 파일을 사용합니다. 처음 배운다면 수동 경로를 추천합니다.

한 터미널에 입력한 환경변수는 다른 터미널에 자동 전달되지 않습니다. 각 실습 앞의 실행 위치와 새 터미널 준비 안내를 확인하세요.
