# 05 설명 — 트레이스과 Tempo

트레이스은 요청 하나가 어떤 서비스를 거쳤고 각 단계에서 얼마나 시간을 썼는지 기록한 데이터입니다.

Tempo는 트레이스를 저장하고 찾아줍니다. 요청 전체의 식별 번호가 Trace ID이고, 그 안의 처리 단계 하나가 span입니다. span마다 시작 시각과 소요 시간이 있어 Grafana에서 가로 시간 막대로 볼 수 있습니다.

이번 실습의 흐름은 **Spring Boot·FastAPI → 중앙 Alloy → Tempo → SeaweedFS의 tempo-traces**입니다. Tempo는 S3를 사용하면서도 처리 중인 기록을 로컬 PVC에 보관합니다.

설치를 단순하게 배우기 위해 한 프로세스가 내부 역할을 함께 수행하는 방식으로 실행합니다. 많은 사용자를 위한 분산·고가용성 구성은 심화에서 다룹니다.

예를 들어 Spring Boot가 FastAPI를 기다리느라 오래 걸렸다면 Spring Boot의 긴 막대 안에 FastAPI 호출 막대가 보입니다. 전체 처리 시간은 중첩된 막대 길이를 모두 더한 값이 아닙니다. 요청이 겹쳐 처리된 관계를 함께 읽습니다.

나중에는 점도표의 점 하나를 선택하여 그 요청의 시간 막대를 열겠습니다. 지금은 저장 도구를 설치하는 단계입니다. 샘플 서버를 계측하기 전에는 트레이스가 없는 것이 정상입니다.
