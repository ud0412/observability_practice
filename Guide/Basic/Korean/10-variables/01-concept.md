# 10 설명 — 고정한 노드 이름을 선택 목록으로 바꾸기

지금까지 worker 이름을 각 쿼리에 직접 입력했습니다. control-plane을 보고 싶다면 여러 쿼리를 고쳐야 합니다.

**변수(Variable)**는 사용자가 선택한 값을 여러 곳에서 함께 사용하는 방법입니다. `node`라는 변수를 만들면 Dashboard 위쪽에 노드 선택 목록을 표시하고, 여러 패널의 쿼리에서 `$node`를 참조할 수 있습니다.

처음에는 노드 하나만 선택합니다. 그다음 여러 노드 선택과 전체 선택을 추가합니다. 여러 값을 선택할 수 있게 되면 쿼리도 여러 이름을 받아들일 수 있어야 합니다.

`node="이름"`은 한 이름과 정확히 일치하는 조건입니다. `node=~"${node:regex}"`는 선택한 여러 이름을 조건으로 사용할 수 있는 형태입니다. Basic에서는 이 패턴을 그대로 사용하고 복잡한 정규식 작성은 하지 않습니다.

변수 이름 `node`와 데이터의 label 이름 `node`를 동일하게 사용해 이해하기 쉽게 만듭니다. 화면의 표시 이름은 `노드`로 지정할 수 있습니다. 이름과 표시 이름은 다른 설정입니다.
