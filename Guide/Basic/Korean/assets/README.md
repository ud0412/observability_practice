# 실제 화면 자료와 검증 범위

`dashboard-add-panel.png`는 실습자가 대화에서 제공한 새 Dashboard 실제 캡처입니다. 로그인 정보나 데이터 내용은 포함하지 않습니다. 원본 화면을 변형하지 않고 사용합니다. Add/Panel/Variable 위치 설명은 이 화면과 대조했습니다.

그 밖의 화면 경로는 Grafana v13.2 공식 문서의 메뉴와 옵션을 기준으로 작성했습니다. 이 변경 작업에서 AI는 WSL 클러스터나 Grafana를 설치하지 않았고, 로그인 후 전체 UI 실습을 실행하지 않았습니다. 공식 문서 대조와 실제 사용자 화면 대조를 전체 실습 재현으로 표현하지 않습니다.

새 실제 캡처를 추가할 때는 고정 버전·영어 UI·학습 단계 번호를 함께 기록하고 비밀번호·토큰·개인 데이터를 제외합니다. 설치된 UI에서 마지막으로 확인한 결과는 [검증 기록](../validation.md)에 남깁니다.
