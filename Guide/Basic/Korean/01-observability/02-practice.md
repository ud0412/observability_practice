# 01 실습 — 세 가지 데이터 구분하기

설치 명령 없이 기록을 읽는 짧은 실습입니다.

1. `CPU 사용률 32%`는 메트릭입니다. 시간별 값이 쌓이면 선그래프가 됩니다.
2. `test request completed`는 로그입니다. 언제 어느 서비스에서 남긴 기록인지 함께 봅니다.
3. `Spring Boot 처리 1.1초, 그 안의 FastAPI 호출 1.0초`는 트레이스로 확인할 수 있는 정보입니다.

아래 요청 흐름을 읽어 보세요.

```text
Windows 브라우저의 Test 버튼
    → Spring Boot /test
        → FastAPI /test
        ← 처리 결과
    ← 최종 응답
```

생각해 볼 것: CPU가 높다는 숫자만으로 특정 요청의 어느 단계가 느린지 알 수 있을까요? 전체 숫자는 메트릭으로, 특정 요청의 단계는 트레이스로, 처리 내용을 로그로 확인합니다.
