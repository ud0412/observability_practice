# 09 설명 — 어떤 그래프를 선택할까요?

같은 숫자라도 확인하려는 내용에 맞춰 표현을 고릅니다.

| 궁금한 것 | 표현 | 읽는 방법 |
|---|---|---|
| 최근 값 하나 | Stat | 큰 숫자 읽기 |
| 시간에 따라 어떻게 변했나 | Time series 선그래프 | 가로 시간, 세로 값 |
| 대상마다 얼마나 다른가 | Bar chart 막대그래프 | 대상 이름과 막대 높이 비교 |
| 정해진 범위 안에서 현재 어디인가 | Gauge 호형 계기판 | 0~100 범위와 현재 위치 |
| 여러 대상의 현재 사용률 | Bar gauge | 각 대상의 가로 막대 길이 |
| 정확한 이름·숫자 목록 | Table | 행과 열로 비교 |
| 무슨 일이 발생했나 | Logs | 시간순 메시지 읽기 |

호형 계기판은 Grafana의 Gauge에서 **Arc** 스타일로 선택합니다. 엄밀한 180도 반원 모양을 지정하는 기능과는 다르지만, 계기판 방식의 표현을 배울 수 있습니다.

**단위(Unit)**는 숫자가 무엇인지 알려 줍니다. 0~100으로 계산한 사용률은 `Percent (0-100)`을 선택합니다. **Threshold**는 값이 특정 기준을 넘으면 색을 바꾸는 설정입니다. 이 실습의 70·90은 표현 연습용 기준이며 실제 장애 기준으로 단정하지 않습니다.

시간에 따른 데이터는 Range 조회로, 현재 대상별 비교는 Instant 조회로 요청합니다. Bar chart는 대상 이름과 숫자가 있는 표 형태의 데이터가 필요합니다. 다음 실습에서 조회 형태까지 함께 바꿉니다.

노드 사용량은 해당 노드 전체를 보는 숫자이고, Pod 사용량은 그 안에서 실행 중인 작업을 보는 숫자입니다. Pod CPU의 단위인 core에서 1은 논리 CPU 하나만큼의 사용량입니다. 메모리는 bytes를 읽기 쉬운 IEC 단위로 표현합니다. 파일시스템 사용률은 선택한 mountpoint의 공간 사용 비율입니다.
