# 03 설명 — 메트릭과 Mimir

메트릭은 CPU 사용률처럼 숫자를 시간과 함께 기록한 데이터입니다.

Mimir는 메트릭을 받아 저장하고 조회합니다. Grafana는 Mimir에게 숫자를 요청해 선그래프나 게이지를 그립니다.

이번 실습의 흐름은 **Alloy → Mimir → SeaweedFS의 mimir-blocks**입니다. Mimir는 S3를 사용하면서도 처리 중인 기록을 로컬 PVC에 보관합니다.

설치를 단순하게 배우기 위해 한 프로세스가 내부 역할을 함께 수행하는 방식으로 실행합니다. 많은 사용자를 위한 분산·고가용성 구성은 심화에서 다룹니다.

메트릭에는 계속 증가하는 요청 수처럼 누적값도 있습니다. 이후 실습에서 최근 증가 속도를 계산해 초당 요청 수로 표현합니다. 지금은 복잡한 수식보다 숫자가 어디에 저장되는지 이해하면 됩니다.
