# 15 설명 — 같은 요청의 로그와 트레이스를 연결하기

트레이스에서 느린 단계를 찾았다면 그 단계가 남긴 메시지를 읽고 싶습니다. 반대로 오류 로그에서 문제가 된 요청의 흐름을 열 수도 있습니다.

연결 기준은 Trace ID입니다. 두 서버가 같은 요청을 처리하는 동안 같은 Trace ID를 로그에 넣습니다. Grafana의 Loki 데이터 소스는 JSON 로그에서 ID를 찾아 Tempo 링크를 만듭니다. Tempo 데이터 소스에는 현재 span의 서비스와 Trace ID로 Loki를 조회하는 연결이 설정되어 있습니다.

로그의 ID가 항상 있는 것은 아닙니다. 앱 시작 메시지처럼 요청 바깥에서 발생한 기록에는 활성 트레이스가 없습니다. 실습에서는 Test 요청 중의 로그를 확인합니다.

시간 범위도 맞아야 합니다. 트레이스를 볼 때 해당 요청 전후의 로그를 검색하도록 1분 여유를 둡니다.
