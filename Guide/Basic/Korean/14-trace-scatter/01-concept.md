# 14 설명 — 점 하나를 요청 하나로 읽기

트레이스 점도표에서는 **점 하나가 Spring Boot에 들어온 /test 요청 하나**입니다. 가로축은 시작 시각이고, 세로축은 그 요청의 처리 시간입니다. 위쪽 점일수록 더 오래 걸린 요청입니다.

메트릭으로 계산한 평균값만 그리면 각 점이 어떤 요청인지 알 수 없습니다. 이번에는 Tempo의 실제 요청 span 결과를 사용하고 같은 행의 Trace ID도 유지합니다. 그래야 점을 클릭했을 때 정확한 요청을 열 수 있습니다.

**워터폴**은 요청 내부 단계들을 가로 시간 막대로 보여주는 화면입니다. 막대의 왼쪽 위치는 시작, 길이는 처리 시간입니다. 부모의 막대 안에 자식 호출이 포함될 수 있으므로 길이를 모두 더하지 않습니다.

실습에서는 Spring의 서버 span만 검색해 요청당 한 점을 만듭니다. 여러 서비스의 모든 span을 그리면 한 요청에 여러 점이 생겨 뜻이 달라집니다.

점에 **Data link**를 연결해 Trace ID를 Grafana Explore로 넘깁니다. 느린 점 → 상세 시간 막대 → 관련 로그를 보는 흐름입니다. 공개 Dashboard는 이번 과정에 포함하지 않습니다.
