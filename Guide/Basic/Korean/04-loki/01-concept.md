# 04 설명 — 로그과 Loki

로그은 요청 시작·완료·오류처럼 서비스가 남긴 사건 기록입니다.

Loki는 로그를 저장하고 검색합니다. 로그에는 시간과 메시지가 있고, namespace·service_name 같은 이름표로 원하는 기록을 좁힙니다. 이 이름표를 label이라고 부릅니다.

이번 실습의 흐름은 **컨테이너 stdout → 노드 Alloy → Loki → SeaweedFS의 loki-data**입니다. Loki는 S3를 사용하면서도 처리 중인 기록을 로컬 PVC에 보관합니다.

설치를 단순하게 배우기 위해 한 프로세스가 내부 역할을 함께 수행하는 방식으로 실행합니다. 많은 사용자를 위한 분산·고가용성 구성은 심화에서 다룹니다.

로그의 Trace ID는 내용으로 저장합니다. 요청마다 다른 ID를 검색용 label로 만들지 않습니다. 나중에 이 ID로 트레이스를 연결합니다.
