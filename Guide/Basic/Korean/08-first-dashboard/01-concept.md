# 08 설명 — 먼저 패널 하나만 완성하기

Dashboard는 여러 패널을 모은 화면입니다. 패널 하나는 데이터 소스, 쿼리, 표현 방식으로 구성됩니다. 같은 쿼리 결과도 큰 숫자로 보거나 선그래프로 볼 수 있습니다.

첫 목표는 노드 Alloy의 수집 성공 여부를 숫자로 보여주는 것입니다. Mimir의 `up` 메트릭에서 값 `1`은 해당 수집 대상의 최근 수집 성공을 뜻하고 `0`은 실패를 뜻합니다.

처음에는 worker 노드 이름을 쿼리에 직접 씁니다. 아직 선택 목록이나 변수는 만들지 않습니다. 결과를 본 뒤 저장하고 다시 열어 보는 것까지가 첫 실습입니다.

영어 UI에서 **Panel**은 패널, **Query**는 조회 문장, **Visualization**은 표현 방식, **Save**는 저장입니다. 새 Dashboard에서는 화면 오른쪽 Add 영역에서 패널을 추가합니다.
