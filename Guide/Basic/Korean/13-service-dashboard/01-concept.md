# 13 설명 — 서비스가 얼마나 처리하고 얼마나 느린가요?

인프라 Dashboard가 노드 자원을 보여줬다면 서비스 Dashboard는 사용자의 요청을 보여줍니다.

**요청 수**는 기간 동안 처리한 개수입니다. **처리율**은 초당 몇 요청을 처리하는지입니다. **오류율**은 전체 요청 중 실패 응답의 비율입니다. **평균 응답 시간**은 걸린 시간을 모두 더해 요청 수로 나눈 값입니다.

**p95 응답 시간**은 관찰한 요청 중 약 95%가 그 시간 이하에 처리되었다는 뜻입니다. 요청이 몇 개뿐이면 p95를 정밀한 성능 결과처럼 해석하기 어렵습니다. 이번에는 느린 요청을 만든 뒤 그래프가 달라지는 것을 관찰합니다.

처음에는 Spring Boot를 고정하여 패널을 만듭니다. 그다음 service_name 변수를 만들고 FastAPI로 전환합니다. 두 서버의 메트릭과 로그가 같은 선택에 반응하도록 바꾸는 것이 목표입니다.
